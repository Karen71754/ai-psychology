# AI Psychology

Русскоязычный прототип ИИ-помощника для эмоциональной поддержки и саморефлексии. Стек: Next.js, TypeScript, OpenAI Responses API.

## Локальный запуск

Требуется Node.js 20.9+ и API-ключ OpenAI.

```bash
npm install
cp .env.example .env.local
```

Добавьте ключ в `.env.local`:

```env
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-6.1-sol
```

Затем выполните `npm run dev` и откройте http://localhost:3000.

## Сейчас реализовано
- Адаптивный русскоязычный чат.
- Серверный вызов OpenAI Responses API.
- Начальная системная инструкция психологического помощника.
- Ограничение размера истории и сообщений.
- API-ключ не передаётся в браузер.
- `store: false` для ответов модели.

## Пока не реализовано
Аккаунты, постоянная память, дневник настроения, валидированные опросники, полноценная кризисная маршрутизация, специальные сценарии защиты несовершеннолетних, согласие и управление персональными данными, экспорт/удаление, rate limiting, мониторинг, мобильное приложение и Telegram.

**Не запускайте прототип как публичный сервис психологической помощи до реализации и проверки перечисленных мер.** Нужны экспертная проверка специалистами по психическому здоровью, безопасности детей и защите данных в странах запуска. Не сохраняйте чувствительные сведения без отдельного согласия.

## Архитектурное направление
Психологическая инструкция находится в `src/lib`, чтобы её можно было повторно использовать для веба, мобильного приложения и Telegram. Постоянная память должна быть включаемой пользователем, прозрачной, редактируемой и удаляемой.
